# 티웨스트 Review Desk

네이버 스마트스토어·쿠팡윙·에이블리 리뷰를 한 페이지에서 보는 Windows용 로컬 웹앱입니다. 네이버는 OpenAI GPT 추천 초안을 수정한 뒤 사용자가 답글을 등록하며, 쿠팡과 에이블리는 조회만 지원합니다.

## 실행

`리뷰관리 실행.cmd`를 더블클릭합니다. [리뷰 관리 열기](http://127.0.0.1:4317)

Node.js 22 이상과 Chrome 또는 Edge가 필요합니다. 처음 설치하거나 다른 PC로 옮겼다면 이 폴더에서 `npm install`을 한 번 실행합니다. 터미널 실행은 `npm start`입니다.

## 사용 순서

1. **네이버 연결 창 열기**를 누릅니다. 별도 Chrome 프로필에서 판매자 계정으로 직접 로그인하고 추가 인증을 완료합니다. 이 창은 열린 채로 두세요.
2. **쿠팡윙 연결**을 눌러 쿠팡 판매자 계정에도 로그인하거나, **쿠팡 연결 설정**에 로그인 정보를 저장해 자동 연결합니다. **에이블리 연결**을 누르면 [에이블리 판매자센터](https://my.a-bly.com/reviews)가 열립니다. 로그인과 추가 인증은 직접 완료하세요. 상단 **전체 / 네이버 / 쿠팡 / 에이블리** 또는 왼쪽 스토어 이름으로 스토어를 선택하고, 조회 기간을 정한 뒤 **리뷰 가져오기**를 누릅니다. 전체를 선택하면 세 스토어를 함께 새로고침합니다. 연결이 끊긴 스토어는 기존 목록을 유지하고 오류를 안내합니다.
3. **브랜드 · GPT 설정**에 브랜드명, 말투, 운영 지침과 OpenAI API 키를 입력합니다. 기본 모델은 `gpt-5-mini`이며 변경할 수 있습니다.
4. 네이버 리뷰를 선택하고 **이번 추천의 말투**에서 원하는 톤을 고른 뒤 **GPT 추천받기**를 누르거나 직접 답글을 작성합니다. **직접 설정하기**에서는 원하는 말투를 200자까지 입력할 수 있습니다. 선택한 톤은 해당 리뷰의 추천 요청에만 적용되며 브랜드 기본 톤은 유지됩니다. 페이지를 새로 열면 브랜드 기본 톤으로 시작합니다. 초안은 자동 저장됩니다. 기존 초안이 있으면 새 AI 추천을 따로 보여주며 덮어쓰지 않습니다.
5. **등록 내용 확인**에서 원문과 최종 답글을 확인한 다음 **네이버에 등록**을 직접 누릅니다. 앱이 네이버 판매자센터에 입력하고, 등록된 답글을 다시 읽어 일치 여부를 확인합니다.

AI 생성, 초안 저장, 리뷰 동기화, 자동 재로그인만으로는 네이버에 글을 등록하지 않습니다. 기존 답글의 덮어쓰기와 삭제 기능은 제공하지 않습니다.

쿠팡 리뷰에서는 상품·작성일·평점·내용을 확인하고 검색·평점 필터를 사용할 수 있습니다. 답글 편집기·GPT 추천·등록 버튼은 제공하지 않으며 서버도 쿠팡 초안/추천/등록 요청을 거부합니다. 답글 대기 건수와 등록률은 네이버 리뷰만으로 계산합니다. 쿠팡 작성자 이름은 첫 글자 외에 마스킹해서 저장합니다.

에이블리는 상품·작성일·내용·사진과 **만족/불만족**을 표시하며 검색과 만족도 필터를 지원합니다. 별점이나 작성자 이름은 제공되지 않아 별점을 임의로 만들지 않고 작성자를 ‘구매자’로 표시합니다. 에이블리 탭은 만족 비율을 보여주고, 통합 평균 별점은 네이버·쿠팡만으로 계산합니다. 에이블리도 답글·GPT 추천·등록 기능을 제공하지 않으며 서버에서 관련 요청을 거부합니다.

에이블리 로그인은 앱 연결용 Chrome 프로필에 유지됩니다. **에이블리 연결 설정**에서 아이디(이메일)와 비밀번호를 한 번 저장해 자동 로그인을 켤 수 있습니다. 로그인 만료나 조회 실패 시 기존 리뷰와 다른 스토어의 초안은 유지됩니다.

## 새 리뷰 자동 가져오기

앱 서버를 시작하면 네이버·쿠팡·에이블리 리뷰를 한 번 확인한 뒤 기본 **10분 간격**으로 새로 가져옵니다. 웹페이지의 **새 리뷰 자동 가져오기**에서 켜기/끄기와 5분·10분·30분·1시간 주기를 선택할 수 있습니다. 설정은 서버를 다시 실행해도 유지됩니다. 각 스토어의 마지막 조회 기간을 사용하며 아직 조회한 적이 없으면 최근 3개월을 사용합니다. 수동으로 조회 기간을 바꾸면 이후 자동 조회도 새 기간을 따릅니다.

웹페이지를 닫아도 로컬 앱 서버가 실행 중이면 수집합니다. PC가 꺼지거나 절전 상태이거나 서버가 종료되면 수집하지 못합니다. 열린 웹페이지는 로컬 저장 결과를 5초마다 확인해 목록과 건수를 갱신하며, 작성 중인 초안·선택한 리뷰·입력 위치를 유지합니다. AI 호출이나 답글 등록은 자동으로 수행하지 않습니다.

로그인이 만료되면 기존 자동 로그인 설정에 따라 재연결하고, 추가 인증이 필요하면 해당 스토어만 대기합니다. 다른 스토어는 계속 조회합니다. 실패 시 기존 캐시를 보존하고 스토어별 상태를 표시하며, 반복 조회 실패는 재시도 간격을 늘립니다. 연결된 판매자 계정이 바뀌면 자동으로 기존 목록을 바꾸지 않으며 직접 스토어를 확인해 다시 가져와야 합니다. 이미 시작한 조회는 완료될 수 있지만, 자동 가져오기를 끄면 대기 중인 조회와 다음 주기부터 중지합니다.

## 자동 로그인 설정

오른쪽 위 **네이버 연결 설정**에서 로그인 방식(네이버 ID / 이메일·판매자 ID)을 선택하고 아이디와 비밀번호를 한 번 입력한 뒤 저장합니다. 채팅에는 로그인 정보를 보내지 마세요. 저장된 값은 화면이나 API 응답으로 다시 반환하지 않습니다.

앱 서버가 실행 중일 때 20초마다 연결을 확인하며, 네이버 서버의 로그인 유효 여부 조회는 최대 1분 동안 재사용합니다. 만료가 확인되면 전용 브라우저에서 정상 로그인 절차를 한 번 시도합니다. 창이 닫혀 있으면 다시 엽니다. PC가 꺼져 있거나 앱 서버가 종료된 동안에는 동작하지 않습니다.

인증번호·캡차·본인 확인 등이 필요하면 자동 처리를 멈추고 앱에 안내합니다. **네이버 연결 창 열기**에서 직접 완료하면 앱이 연결 복구를 인식합니다. 잘못된 비밀번호나 알 수 없는 화면에서는 반복 시도를 중단하고, 이 상태는 앱 재시작 후에도 유지됩니다. 정보를 수정하거나 설정을 다시 저장하면 새로 시도합니다. 연결이 반복해서 만료되면 최소 5분 간격으로 시도합니다. 네이버의 보안 설정은 변경하지 않습니다.

**자동 로그인 끄기**는 체크를 해제한 뒤 저장합니다. **저장된 로그인 정보 삭제**는 암호화된 저장 정보를 삭제하고 자동 로그인을 끕니다. 이미 로그인된 네이버 창의 세션은 유지됩니다. 직접 로그아웃한 상태를 유지하려면 먼저 자동 로그인을 꺼 주세요.

재연결 작업은 리뷰 조회·등록과 같은 대기열에서 처리합니다. 등록 도중 연결이 끊기면 해당 등록을 자동 재전송하지 않습니다. 초안을 확인하고 필요할 때 직접 다시 등록하세요.

**쿠팡 연결 설정**에서도 쿠팡윙 아이디·비밀번호를 한 번 저장해 자동 로그인을 켤 수 있습니다. 쿠팡의 공식 판매자 로그인 폼으로 한 번만 로그인을 시도합니다. 보안 문자·인증번호·기기 확인 등이 필요하면 멈추고 안내하며, **연결 창 · 추가 인증 열기**에서 직접 완료하세요. 잘못된 비밀번호·알 수 없는 화면·중단된 로그인은 반복 시도하지 않고, 확인 대기 상태를 서버 재시작 후에도 유지합니다. 정보를 수정하거나 설정을 다시 저장하면 새로 시도합니다. 반복 만료 시 최소 5분 간격으로 제한합니다.

쿠팡도 앱 실행 중 20초 간격으로 연결을 확인하며, 리뷰 페이지의 실제 서버 로그인 유효 여부 조회는 최대 1분 동안 재사용합니다. 네트워크 장애 때는 비밀번호를 제출하지 않습니다. 쿠팡 재로그인과 리뷰 조회는 같은 대기열에서 처리하며 네이버 설정과 별도로 켜고 끌 수 있습니다. 쿠팡에서 로그아웃 상태를 유지하려면 쿠팡 자동 로그인을 먼저 꺼 주세요.

**에이블리 연결 설정**에서도 같은 방식으로 자동 로그인을 켜고 끌 수 있습니다. 현재 판매자센터의 공식 로그인 폼을 한 번만 제출하고, 추가 인증·보안 문자·잘못된 로그인 정보가 감지되면 멈춥니다. 인증 대기 상태는 서버 재시작 후에도 유지합니다. **연결 창 · 추가 인증 열기**에서 직접 완료하거나, 정보를 수정해 다시 저장하면 됩니다. 에이블리도 20초 간격으로 상태를 확인하며 실제 세션 조회는 최대 1분 동안 재사용합니다. 반복 만료 시 재시도 간격은 최소 5분입니다. 네트워크 장애 때는 로그인 정보를 제출하지 않습니다. 에이블리 리뷰는 계속 조회 전용이며, 재로그인 과정에서 답글을 등록하지 않습니다.

## 데이터와 키

- 웹 서버는 `127.0.0.1:4317`에만 바인딩됩니다. 외부 공개용 서버가 아닙니다.
- 리뷰 캐시, 초안, 등록 요청 상태는 `.local/state.json`, 전용 로그인 프로필은 `.local/naver-browser/`에 보관됩니다. 이 폴더를 다른 사람에게 공유하거나 Git에 추가하지 마세요.
- 자동 로그인 정보는 `.local/naver-auth.json`에 [Windows DPAPI CurrentUser](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.dataprotectionscope?view=netframework-4.8)로 암호화해 저장합니다. 같은 Windows 사용자 계정으로만 복호화하며, 평문 파일·프로세스 인수·로그에 기록하지 않습니다. 다른 PC나 Windows 계정으로 옮긴 경우 다시 입력하세요. GPT에는 보내지 않습니다.
- 쿠팡 자동 로그인 정보는 같은 방식으로 `.local/coupang-auth.json`에 별도로 암호화합니다. 설정 화면·API 응답에 저장된 아이디·비밀번호를 반환하지 않습니다. 쿠팡의 **저장된 로그인 정보 삭제**는 쿠팡 저장 정보와 자동 로그인만 지우며 네이버 설정이나 현재 쿠팡 브라우저 세션은 유지합니다.
- 에이블리 자동 로그인 정보는 `.local/ably-auth.json`에 같은 Windows 암호화 방식으로 별도 저장합니다. 에이블리 설정을 끄거나 삭제해도 네이버·쿠팡 설정에는 영향을 주지 않습니다. 저장된 로그인 정보는 화면·API 응답·로그·GPT에 전달하지 않습니다.
- 설정 화면에서 입력한 API 키는 `.local/openai-key.json`에 Windows DPAPI CurrentUser로 암호화해 저장하며 서버를 다시 실행하면 자동으로 불러옵니다. 평문 키는 브라우저 저장소, API 응답, 로그, 파일에 기록하지 않습니다. 키 변경 시 새 키를 입력하고 저장하세요. **저장된 API 키 삭제 · 연결 해제**를 누르면 암호문과 실행 중 키를 제거하며, 재시작 후에도 해제 상태가 유지됩니다. OpenAI 계정의 키 자체를 폐기하는 기능은 아닙니다.
- 다른 PC나 Windows 계정으로 옮겨 저장된 키를 읽을 수 없을 때는 앱에서 다시 저장하도록 안내합니다. `.env`의 `OPENAI_API_KEY`는 암호화 저장 기록이 없는 경우에만 초기 값으로 사용할 수 있으며, 앱에서 저장한 키와 명시적인 연결 해제 설정이 우선합니다. `.env.example`에는 실제 키를 넣지 마세요.
- GPT에는 상품명, 옵션(조회한 경우), 평점, 리뷰 내용, 브랜드 지침만 전달합니다. 주문번호와 작성자 ID는 전달하지 않습니다. 리뷰의 일반적인 이메일·휴대전화 형식은 마스킹하며, 자유문장에 있는 모든 개인정보를 자동으로 판별하는 기능은 아닙니다.
- API 사용료는 사용자의 OpenAI 계정에 청구됩니다. API 키는 채팅이나 지원 요청에 붙여넣지 마세요.

## 연동 범위와 운영

에이블리는 `my.a-bly.com/reviews` 화면에서 실제 사용하는 리뷰 조회 GET 요청으로 연결합니다. 공식 공개 API 연동이 아니므로 판매자센터 변경에 따라 수정이 필요할 수 있습니다. 인증 값은 메모리에서만 사용하며 앱 API 응답이나 리뷰 파일에 기록하지 않습니다. 현재 조회는 전체 페이지를 읽은 뒤 작성일 기준으로 선택 기간을 적용합니다. 일부 페이지 누락·리뷰 수 변경·중복이 발견되면 기존 목록을 유지하고 다시 조회하도록 안내합니다. 연결 확인과 동기화는 리뷰 등록·수정 요청을 보내지 않습니다.

네이버 커머스 공개 리뷰 API를 사용하는 앱이 아닙니다. 사용자 소유 계정의 판매자센터 화면을 Playwright로 조작합니다. 검증 기준 화면은 2026-11-15 스마트스토어의 `/mg/contents/review/search` iframe입니다. 네이버 화면 변경, 로그인 상태, 운영 정책에 따라 연결 코드를 수정해야 할 수 있습니다. 장기 운영 전 판매자센터 자동화 허용 범위를 확인하세요.

네이버 연결 창에서 다른 스토어로 바꾸면 기존 목록에 대한 등록을 차단합니다. 먼저 앱에서 리뷰를 다시 동기화하세요. 다른 작업 중에는 앱 연결용 네이버 창을 직접 조작하지 않는 것이 좋습니다.

조회 기간은 최근 1·3·6개월 또는 1년입니다. 가상 스크롤과 페이지 이동으로 리뷰를 모으며 최대 100페이지까지 읽습니다. 화면에 표시된 전체 건수와 수집 건수가 다르면 기존 캐시를 유지하고 오류를 알립니다.

쿠팡은 로그인된 전용 Chrome의 쿠팡윙 `/tenants/cs/product/review` 화면과 같은 세션에서 실제 화면의 `/tenants/cs/product/review/search` 조회 요청만 사용합니다. 공개 Open API 연동은 아니며 쿠팡윙 변경 시 조정이 필요할 수 있습니다. 판매중·판매종료 상품을 모두 포함하고, 쿠팡의 1개월 조회 제한에 맞춰 최대 28일씩 기간을 나눠 모든 페이지를 합칩니다. 조회 건수와 실제 수집 건수가 다르거나 조회 도중 판매자 계정이 바뀌면 기존 캐시를 보존합니다. 최대 300개 조회 요청을 허용하며 초과하면 기간을 줄이도록 안내합니다.

쿠팡 로그인은 전용 Chrome 프로필에 유지됩니다. 자동 로그인을 설정하면 만료 시 재연결을 시도합니다. 추가 인증이 필요하거나 자동 로그인을 꺼 둔 경우 **쿠팡윙 연결/열기**에서 직접 완료한 뒤 다시 새로고침하세요. 네이버와 쿠팡의 자동 로그인은 각각 설정합니다. 쿠팡 연결 창은 조회 중 직접 조작하지 마세요.

등록 직후 연결이 끊기는 등 결과가 불명확하면 재전송하지 않고 상태를 기록합니다. **네이버 답글 확인**으로 결과를 확인하세요. 같은 문구 재등록은 중복 방지를 위해 차단합니다. 이미 등록된 글의 수정·삭제가 필요하면 판매자센터에서 직접 처리하세요.

등록 완료 안내창은 앱이 닫은 뒤 네이버의 실제 답글을 다시 읽습니다. 등록 후 확인 단계만 실패했을 때에도 재등록하지 않고 조회로 결과를 복구합니다. 등록이 확인되면 초안과 미확인 기록을 정리하며, 다른 앱 탭에도 5초마다 또는 탭으로 돌아왔을 때 저장된 등록 상태를 반영합니다. 이 화면 갱신은 로컬 저장 상태를 읽고, 스토어 전체 리뷰 조회는 위 자동 가져오기 주기로 별도 수행합니다.

## 구성과 검증

- `src/naver.js`: 전용 브라우저, 리뷰 수집, 대상 검증, 등록 및 재조회
- `src/coupang.js`, `src/coupang-service.js`: 쿠팡 조회 전용 연결, 기간·페이지 분할, 통합 캐시
- `src/ably.js`, `src/ably-service.js`: 에이블리 조회 전용 연결, 만족도·사진·작성 기간, 통합 캐시
- `src/ably-login.js`: 에이블리 공식 로그인 폼, 단일 로그인 시도, 추가 인증 대기
- `src/auto-sync.js`: 세 스토어의 자동 리뷰 조회, 주기·실패·복구 상태, 중복 작업 방지
- `src/coupang-login.js`: 쿠팡 공식 로그인 폼 확인, 단일 로그인 시도, 추가 인증 대기
- `src/naver-login.js`, `src/auto-login.js`: 정상 로그인 시도, 추가 인증 대기, 중복 시도 방지
- `src/auth-vault.js`: Windows 사용자 계정에 묶인 로그인 정보 암호화 저장
- `src/core.js`: 초안 저장, 사용자 확인 토큰, 중복·불확실한 등록 방지
- `src/ai.js`: OpenAI Responses API로 초안만 생성
- `src/api-key-vault.js`: OpenAI 키 암호화 저장·시작 시 복원·삭제
- `src/server.js`: 동일 출처·CSRF 검사와 로컬 API
- `public/`: 반응형 리뷰 목록, 필터, 답글 편집기, 설정 화면

`npm test`는 등록 경로와 HTTP 경계 테스트를 수행합니다. 브라우저 UI 테스트는 로컬 서버가 실행되어 있어야 하며 모든 API를 모의 처리하므로 실제 고객 리뷰를 게시하지 않습니다. `npm run check`는 JavaScript 구문 검사입니다.

`scripts/verify-live.mjs`는 이미 등록된 답글만 재조회합니다. `scripts/verify-fill.mjs`는 미답변 리뷰 입력창에 임시 문구를 입력한 후 지우며 등록 버튼을 누르지 않습니다. `scripts/screenshots.mjs`는 실제 화면의 데스크톱·모바일 레이아웃을 확인합니다.

`scripts/verify-coupang.mjs`는 네이버의 마지막 조회 기간에 맞춰 실제 쿠팡 리뷰만 새로고침하고, 네이버 리뷰·초안 보존 및 데스크톱·모바일 조회 전용 화면을 검증합니다. 리뷰를 게시하지 않습니다.

`node scripts/verify-ably.mjs 6m`은 실제 에이블리 리뷰를 읽어 건수·기간·사진·만족도를 확인하며 앱 캐시는 변경하지 않습니다. `node scripts/check-ably-app.mjs`는 실행 중인 앱에 에이블리 리뷰를 동기화하고, 다른 스토어의 리뷰·초안 보존 및 실제 사진·스토어별 탭·모바일 화면을 검증합니다. 두 스크립트 모두 에이블리 연결 창에 로그인한 상태가 필요하며 리뷰를 게시하지 않습니다.

`node scripts/verify-ably-login.mjs`는 저장된 에이블리 자동 로그인 정보로 별도 임시 브라우저 세션에서 실제 로그인과 리뷰 조회를 검증합니다. 현재 연결 창과 앱 캐시는 변경하지 않으며, 결과와 건수만 출력합니다. 검증 세션에서 추가 인증이 요구되면 자동 처리를 멈추고 결과를 알립니다.

외부 호스팅은 포함하지 않습니다. 이 PC에서 앱 서버와 연결용 브라우저를 실행해 사용합니다.
