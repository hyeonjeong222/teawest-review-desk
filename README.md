# 티웨스트 Review Desk

네이버 스마트스토어·쿠팡윙·에이블리·배민·쿠팡이츠 리뷰를 관리하는 Windows용 로컬 웹앱입니다. 네이버·배민·쿠팡이츠는 GPT 추천 초안을 수정하고 확인한 뒤 답글을 등록할 수 있으며, 쿠팡윙과 에이블리는 조회만 지원합니다. 배민과 쿠팡이츠는 티웨스트·베스티를 각각 별도 채널로 관리합니다.

## 설치 파일로 시작하기 (권장)

1. [Windows 설치 파일 다운로드](https://github.com/hyeonjeong222/teawest-review-desk/releases/latest/download/ReviewDesk-Setup-x64.exe)를 누릅니다. GitHub 로그인은 필요 없습니다.
2. `ReviewDesk-Setup-x64.exe`를 더블클릭하고 **설치하기**를 누릅니다. 예전 ZIP 버전을 사용했다면 자동으로 찾은 폴더를 확인하세요. 찾지 못하면 **폴더 선택**으로 기존 `리뷰관리 실행.cmd`가 있는 폴더를 선택합니다.
3. **리뷰 앱 열기**를 누릅니다. 다음부터는 바탕화면이나 시작 메뉴의 **리뷰 관리**를 더블클릭하면 됩니다.
4. 처음 사용하는 PC는 연결 설정에 판매자 계정을 저장하고, 브랜드 · GPT 설정에 본인의 API 키를 입력합니다. 이미 이 PC에 저장했던 키·로그인은 이전 후 그대로 사용합니다. 추가 인증은 앱에서 여는 연결 창에서 직접 완료하세요.

Windows 10/11 **x64**, Chrome 또는 Edge와 인터넷 연결이 필요합니다. Node.js 설치, 터미널 명령, 관리자 권한은 필요 없습니다. 현재 설치 파일에는 코드 서명이 없어 Windows에 게시자 확인 안내가 나타날 수 있습니다.

**업데이트:** 앱 오른쪽 위 **업데이트 → 업데이트 확인 → 다운로드 및 설치**를 누르고 설치 창을 완료하세요. 작성 중인 초안은 먼저 저장하고 진행 중인 작업을 마친 뒤 앱을 종료합니다. GitHub의 정식 릴리스에서 설치 파일을 받아 크기와 SHA-256을 검증합니다. 설치 창을 취소했으면 다시 **업데이트 확인**부터 진행할 수 있습니다. GitHub에서 최신 설치 파일을 다시 실행해도 같은 방식으로 업데이트됩니다.

프로그램은 `%LOCALAPPDATA%\ReviewDesk\versions`, 각 PC의 리뷰·초안·설정·암호화된 로그인 정보와 API 키는 **`%LOCALAPPDATA%\ReviewDesk\data`**에 별도로 저장합니다. 업데이트는 이 데이터 폴더를 덮어쓰지 않습니다. 이전 프로그램 폴더도 자동 삭제하지 않으며, 이전 정보가 정상적으로 보이는지 확인한 뒤 직접 정리할 수 있습니다. 최초 가져오기는 같은 Windows 사용자 계정에서만 가능합니다. 다른 PC/Windows 계정 간에는 앱의 암호화된 로그인 이전 파일 기능을 사용하세요. 브라우저 쿠키는 복사하지 않아 추가 인증이 다시 요구될 수 있습니다.

각 PC는 독립적으로 동작합니다. 운영자가 수정한 코드는 새 설치 버전으로 배포되며, 각 사용자는 앱에서 업데이트합니다. 저장된 계정·API 키·고객 리뷰는 GitHub에 업로드하지 않습니다. 판매자 사이트 변경으로 연결 방식이 바뀌면 앱 업데이트가 필요할 수 있습니다.

### 운영자의 새 버전 배포

`package.json`과 `package-lock.json`의 버전을 함께 올린 뒤 Windows x64에서 실행합니다.

```powershell
npm ci
npm test
npm run package:installer
node scripts/verify-installer.mjs dist/installer-버전/ReviewDesk-Setup-x64.exe
```

빌드는 공식 배포본과 해시가 일치하는 Node.js 런타임·의존성을 포함하고 Windows 기본 .NET Framework C# 컴파일러로 설치 파일을 만듭니다. 별도 설치 도구 라이선스는 필요하지 않습니다. 소스를 커밋·푸시하고 GitHub에 **`v버전`** 정식 릴리스를 만드세요. `dist/installer-버전`의 **`ReviewDesk-Setup-x64.exe`**, **`review-desk-update.json`**, **`SHA256SUMS.txt`** 세 파일을 함께 첨부합니다. 초안/사전 릴리스는 업데이트에 표시되지 않습니다. 배포 전 실제 키가 아닌 시험용 계정으로 이전·업데이트·바로가기·실행을 검증합니다. 설치 프로그램은 이전 버전으로의 덮어쓰기를 거부합니다.

## 배민·쿠팡이츠 매장별 사용

- **배민 · 티웨스트 / 배민 · 베스티 / 쿠팡이츠 · 티웨스트 / 쿠팡이츠 · 베스티** 탭에서 각각 리뷰를 가져옵니다. 실제 계정의 매장 이름과 번호를 함께 확인하며 같은 리뷰 번호라도 플랫폼·매장별로 별도 저장합니다.
- 배민·쿠팡이츠도 연결 설정에 아이디와 비밀번호를 저장해 자동 로그인할 수 있습니다. 추가 인증·보안 문자·필수 비밀번호 변경은 연결용 Chrome에서 직접 완료합니다.
- 리뷰 선택 → **GPT 추천받기** → 초안 수정 → **등록 내용 확인** → 확인창의 **해당 매장에 등록** 순서로 게시합니다. 확인창에 서비스·매장·원문·최종 답글을 표시합니다. 추천이나 자동 조회만으로 게시하지 않습니다.
- 해당 채널을 선택한 상태에서 **브랜드 · GPT 설정**을 열면 그 채널의 말투와 운영 지침을 따로 저장합니다. GPT의 브랜드 이름은 티웨스트 또는 베스티로 고정하고, API 키와 모델은 함께 사용합니다.
- 배민도 **1·3·6개월·1년**을 조회합니다. 공식 화면의 '날짜 직접 선택'은 한 번에 6개월까지 조회하므로, 1년은 겹치지 않는 구간으로 나눠 모두 읽고 합칩니다. 각 구간의 전체 건수와 수집 건수를 확인하며 하나라도 실패하면 기존 목록을 유지합니다. 배민이 댓글 등록을 허용하지 않는 과거 리뷰는 조회만 가능합니다.
- 쿠팡이츠는 **1·3·6개월·1년**을 조회하며 기간을 나눠 전체 페이지를 수집합니다. 현재 사이트의 **300자 / 작성 후 14일 이내** 제한을 반영합니다. 등록 기간이 지난 리뷰도 조회할 수 있습니다.
- 네 채널의 자동 조회 주기는 기존 자동 가져오기 설정을 따릅니다. 리뷰·초안·등록 상태·마지막 조회 기간은 각 채널별로 유지합니다. 같은 서비스의 두 매장은 한 번에 하나씩 처리합니다.
- 등록 후 실제 답글을 다시 읽습니다. 결과가 불확실하면 같은 리뷰에 다른 문구로 재시도하는 것도 막고 **답글 확인**으로 결과를 확인하도록 안내합니다. 이미 등록된 답글의 수정·삭제는 제공하지 않습니다.

배민은 공식 화면에서 발생한 읽기 응답을 수집하고, 쿠팡이츠는 로그인된 브라우저에서 실제 리뷰 화면의 읽기 요청을 사용합니다. 공개 API 연동이 아니므로 사이트 변경 시 조정이 필요할 수 있습니다. 게시 동작은 두 사이트의 리뷰별 입력창과 등록 버튼을 사용합니다.

`node scripts/verify-delivery.mjs baemin-teawest --fill`은 실제 리뷰를 조회하고 임시 문구 입력 후 지우고 취소합니다. `baemin-besti`, `coupangeats-teawest`, `coupangeats-besti`도 지정할 수 있습니다. 이 검증은 등록 버튼을 누르지 않습니다. 게시·매장 분리·중복 방지는 `tests/delivery.test.js`, `tests/delivery-ui.test.js`의 모의 데이터로 검증합니다.

## 소스 및 기존 ZIP 방식으로 실행

`리뷰관리 실행.cmd`를 더블클릭합니다. [리뷰 관리 열기](http://127.0.0.1:4317)

소스 폴더로 실행할 때는 Node.js 22 이상과 Chrome 또는 Edge가 필요합니다. 처음 설치한 소스 폴더에서는 `npm ci`를 한 번 실행합니다. 터미널 실행은 `npm start`입니다.

### 다른 Windows PC에서 별도로 실행

`dist/`의 `ReviewDesk-Windows-x64-날짜.zip`을 다른 PC로 복사하고 **압축을 모두 푼 뒤 `리뷰관리 실행.cmd`를 더블클릭**합니다. 실행에 필요한 Node.js와 모듈이 포함되어 Node.js 설치나 관리자 권한이 필요 없습니다. Windows 10/11 x64와 Chrome 또는 Edge, 인터넷 연결이 필요합니다. 사용자 계정에 설치된 Chrome/Edge도 자동으로 찾습니다.

로그인 정보도 그대로 쓰려면 기존 PC의 **스토어 연결 설정 → 다른 PC로 로그인 정보 옮기기**에서 이전용 암호(10자 이상)를 정하고 파일을 만드세요. 새 PC에서 최신 실행본을 열고 같은 메뉴에서 파일과 암호를 입력해 복원합니다. 다섯 서비스의 저장된 아이디·비밀번호, 자동 로그인 사용 여부, 네이버 로그인 방식과 GPT 키를 한 번에 이전하고 새 PC의 Windows 계정으로 다시 암호화해 저장합니다. 새 PC에서 추가 인증이 요구되면 직접 완료하세요.

PC마다 리뷰·초안·설정은 별개이며 서로 자동 공유하지 않습니다. 실제 판매자센터에 등록한 답글은 다른 PC에서도 다음 조회에 반영됩니다. 웹 서버와 브라우저 연결은 해당 PC의 루프백 주소에서만 동작하며 외부 배포는 없습니다. 비밀번호 변경 후에는 사용하는 PC마다 연결 설정을 갱신하거나 새 이전 파일을 복원하세요.

프로그램 압축 파일에는 `.local`, `.env`, 로그인 세션, API 키, 비밀번호, 고객 리뷰를 포함하지 않습니다. 별도로 만드는 로그인 이전 파일은 scrypt로 키를 유도하고 AES-256-GCM으로 암호화합니다. 이전용 암호는 저장하지 않으며 분실 시 기존 PC에서 새 파일을 만들어야 합니다. 복원할 때 파일에 포함된 계정과 키만 교체하고 그 외 연결 설정은 유지합니다. 잘못된 암호·변조된 파일은 적용하지 않으며 저장 실패와 실행 중단에는 암호문으로 된 복구 기록을 사용합니다. 리뷰·초안·쿠키는 로그인 이전 파일에 포함하지 않습니다. 선택적인 리뷰·초안 이전은 `다른 PC 사용 안내.txt`를 참고하세요.

프로그램 변경 후 새 실행본은 `npm run package:windows`로 만듭니다. 이 명령은 Windows x64의 현재 Node.js 실행 파일과 라이선스, 잠금 파일과 버전이 일치하는 모듈만 포함하며 기존 실행본을 덮어쓰지 않습니다. 패키지의 `SHA256SUMS.txt`와 `BUILD.json`으로 포함 파일과 빌드 정보를 확인할 수 있습니다.

## 사용 순서

다른 PC에서 로그인 후에도 연결되지 않으면 **연결 상태 진단.cmd** 또는 **Check Connection.cmd**를 실행합니다. 앱 서버, 연결용 브라우저, 서비스별 상태를 최대 약 25초 동안 확인하고 `.local/connection-diagnostic-날짜.txt`에 저장합니다. 진단에는 계정·키·쿠키·리뷰·전체 탭 주소를 포함하지 않으며 로그인이나 설정 변경을 수행하지 않습니다. 진단 결과가 실제 원인 확인을 위한 자료이며, 이 도구 자체가 연결을 복구하는 것은 아닙니다.

1. **네이버 연결 창 열기**를 누릅니다. 별도 Chrome 프로필에서 판매자 계정으로 직접 로그인하고 추가 인증을 완료합니다. 이 창은 열린 채로 두세요.
2. **쿠팡윙 연결**을 눌러 쿠팡 판매자 계정에도 로그인하거나, **쿠팡 연결 설정**에 로그인 정보를 저장해 자동 연결합니다. **에이블리 연결**을 누르면 [에이블리 판매자센터](https://my.a-bly.com/reviews)가 열립니다. 로그인과 추가 인증은 직접 완료하세요. 상단 스토어 탭 또는 왼쪽 스토어 이름으로 스토어를 선택하고, 조회 기간을 바꾸면 저장된 리뷰에서 해당 기간을 바로 표시하고 상단 버튼의 수도 함께 바뀝니다. 아직 저장되지 않은 기간만 추가로 가져옵니다. 매장을 전환해도 선택한 기간을 유지합니다. 같은 기간의 최신 리뷰는 **새 리뷰·답글 갱신**으로 확인합니다. 1년을 선택하면 배민도 기간을 나눠 1년 전체를 조회합니다. 조회 중·실패·다른 기간의 기존 결과는 상단에 숫자 대신 상태를 표시하며, 기존 목록에는 실제 조회 기간을 안내합니다. 연결이 끊긴 스토어는 기존 목록을 유지하고 오류를 안내합니다.
3. **브랜드 · GPT 설정**에 브랜드명, 말투, 운영 지침과 OpenAI API 키를 입력합니다. 기본 모델은 `gpt-5-mini`이며 변경할 수 있습니다.
4. 네이버 리뷰를 선택하고 **이번 추천의 말투**에서 원하는 톤을 고른 뒤 **GPT 추천받기**를 누르거나 직접 답글을 작성합니다. **직접 설정하기**에서는 원하는 말투를 200자까지 입력할 수 있습니다. 선택한 톤은 해당 리뷰의 추천 요청에만 적용되며 브랜드 기본 톤은 유지됩니다. 페이지를 새로 열면 브랜드 기본 톤으로 시작합니다. 초안은 자동 저장됩니다. 기존 초안이 있으면 새 AI 추천을 따로 보여주며 덮어쓰지 않습니다.
5. **등록 내용 확인**에서 원문과 최종 답글을 확인한 다음 **네이버에 등록**을 직접 누릅니다. 앱이 네이버 판매자센터에 입력하고, 등록된 답글을 다시 읽어 일치 여부를 확인합니다.

AI 생성, 초안 저장, 리뷰 동기화, 자동 재로그인만으로는 네이버에 글을 등록하지 않습니다. 기존 답글의 덮어쓰기와 삭제 기능은 제공하지 않습니다.

쿠팡 리뷰에서는 상품·작성일·평점·내용을 확인하고 검색·평점 필터를 사용할 수 있습니다. 답글 편집기·GPT 추천·등록 버튼은 제공하지 않으며 서버도 쿠팡 초안/추천/등록 요청을 거부합니다. 답글 대기 건수와 등록률은 선택한 채널의 등록 가능한 리뷰와 답변 완료 리뷰로 계산합니다. 쿠팡 작성자 이름은 첫 글자 외에 마스킹해서 저장합니다.

에이블리는 상품·작성일·내용·사진과 **만족/불만족**을 표시하며 검색과 만족도 필터를 지원합니다. 별점이나 작성자 이름은 제공되지 않아 별점을 임의로 만들지 않고 작성자를 ‘구매자’로 표시합니다. 에이블리 탭은 만족 비율을 보여주며, 다른 스토어의 평점과 섞지 않습니다. 에이블리도 답글·GPT 추천·등록 기능을 제공하지 않으며 서버에서 관련 요청을 거부합니다.

에이블리 로그인은 앱 연결용 Chrome 프로필에 유지됩니다. **에이블리 연결 설정**에서 아이디(이메일)와 비밀번호를 한 번 저장해 자동 로그인을 켤 수 있습니다. 로그인 만료나 조회 실패 시 기존 리뷰와 다른 스토어의 초안은 유지됩니다.

## 새 리뷰 자동 가져오기

리뷰는 이 PC에 누적 저장합니다. 기간을 좁혀도 예전에 가져온 리뷰는 삭제하지 않으며 재시작·업데이트 후에도 유지됩니다. **새 리뷰·답글 갱신**과 자동 가져오기는 최근 구간(네이버·배민·쿠팡이츠 31일, 쿠팡윙 7일)을 다시 읽어 새 리뷰·수정된 리뷰·변경된 답글을 합칩니다. 오래 꺼져 있었으면 마지막 확인 이후의 구간까지 넓힙니다. 에이블리는 수정순 목록의 저장된 확인 지점까지만 읽으며, 건수나 순서가 맞지 않으면 전체를 다시 확인합니다.

오래된 리뷰의 외부 답글 수정도 확인하도록 선택 기간의 과거 28일 구간을 순서대로 점검합니다(최대 10분에 한 구간). 따라서 오래된 답글 변경은 즉시 반영되지 않을 수 있습니다. 선택한 기간을 한 번에 모두 확인하려면 **전체 다시 확인**을 누르세요. 각 서비스가 변경분 전용 조회를 제공하는 방식은 아니어서 일부 최근 리뷰는 다시 읽습니다. 조회 실패나 일부 누락 시 저장된 목록·초안·확인 지점을 유지합니다. 쿠팡윙의 기간 필터는 최초 작성일을 기준으로 표시합니다.

앱 서버를 시작하면 네이버·쿠팡윙·에이블리와 배민·쿠팡이츠의 네 매장 채널을 한 번 확인한 뒤 기본 **10분 간격**으로 새로 가져옵니다. 웹페이지의 **새 리뷰 자동 가져오기**에서 켜기/끄기와 5분·10분·30분·1시간 주기를 선택할 수 있습니다. 설정은 서버를 다시 실행해도 유지됩니다. 상단에서 선택한 공통 기간을 사용하며 아직 선택하지 않았으면 최근 3개월을 사용합니다. 기간을 바꾸면 저장된 목록을 먼저 표시하며, 저장하지 않은 구간은 추가로 조회합니다. 이후 자동 조회도 선택한 기간을 따릅니다. 선택한 공통 기간은 서버 재시작과 다른 브라우저 창에서도 유지합니다.

웹페이지를 닫아도 로컬 앱 서버가 실행 중이면 수집합니다. PC가 꺼지거나 절전 상태이거나 서버가 종료되면 수집하지 못합니다. 열린 웹페이지는 로컬 저장 결과를 5초마다 확인해 목록과 건수를 갱신하며, 작성 중인 초안·선택한 리뷰·입력 위치를 유지합니다. AI 호출이나 답글 등록은 자동으로 수행하지 않습니다.

로그인이 만료되면 기존 자동 로그인 설정에 따라 재연결하고, 추가 인증이 필요하면 해당 스토어만 대기합니다. 다른 스토어는 계속 조회합니다. 실패 시 기존 캐시를 보존하고 스토어별 상태를 표시하며, 반복 조회 실패는 재시도 간격을 늘립니다. 연결된 판매자 계정이 바뀌면 자동으로 기존 목록을 바꾸지 않으며 직접 스토어를 확인해 다시 가져와야 합니다. 이미 시작한 조회는 완료될 수 있지만, 자동 가져오기를 끄면 대기 중인 조회와 다음 주기부터 중지합니다.

## 연결 설정과 비밀번호 업데이트

다섯 서비스의 **연결 설정** 버튼을 같은 영역에서 사용합니다. 다섯 서비스 모두 처음 연결할 때 아이디와 비밀번호를 저장할 수 있습니다. 이후 비밀번호만 바뀌면 **새 비밀번호만 입력하고 설정 저장**을 누르세요. 비워 둔 아이디는 암호화된 기존 계정에서 사용하며, 아무것도 입력하지 않으면 기존 정보가 유지됩니다. 계정 또는 네이버 로그인 방식을 바꾸려면 아이디와 비밀번호를 모두 입력해야 합니다. 저장된 비밀번호는 화면에 다시 표시하지 않으며, 변경 사항은 다음 자동 로그인부터 사용합니다.

배달의민족·쿠팡이츠의 **연결 설정**에서 자동 로그인을 켜고 아이디와 비밀번호를 저장하세요. 배민은 배민비즈회원 아이디를 사용합니다. 서비스별로 티웨스트·베스티가 한 로그인 정보를 함께 사용하며 리뷰·초안·등록 대상은 가게별로 분리됩니다. 비밀번호가 바뀌면 새 비밀번호만 입력해 저장할 수 있습니다. 저장 정보는 각각 `.local/baemin-auth.json`, `.local/coupangeats-auth.json`에 Windows DPAPI로 암호화되며 화면과 API에는 다시 반환하지 않습니다.

로그인이 만료되면 서비스당 한 번씩 공식 로그인 폼으로 재연결합니다. 인증번호·캡차·본인 확인·필수 비밀번호 변경은 자동 처리하지 않고 대기하며 **연결 창 · 추가 인증 열기**로 직접 완료하세요. 잘못된 로그인 정보와 불명확한 실패는 반복 시도하지 않습니다. 새 정보를 저장하면 다시 시도하며, 인터넷 장애에서는 비밀번호를 제출하지 않습니다. 자동 로그인 확인은 같은 서비스의 리뷰 조회·등록과 작업 순서를 공유합니다. 자동 로그인용 별도 탭을 사용하므로 리뷰의 답글 입력창은 건드리지 않습니다.

## 자동 로그인 설정

**스토어 연결 설정** 영역의 **네이버 연결 설정**에서 로그인 방식(네이버 ID / 이메일·판매자 ID)을 선택하고 아이디와 비밀번호를 한 번 입력한 뒤 저장합니다. 채팅에는 로그인 정보를 보내지 마세요. 저장된 값은 화면이나 API 응답으로 다시 반환하지 않습니다.

앱 서버가 실행 중일 때 20초마다 연결을 확인하며, 네이버 서버의 로그인 유효 여부 조회는 최대 1분 동안 재사용합니다. 만료가 확인되면 전용 브라우저에서 정상 로그인 절차를 한 번 시도합니다. 창이 닫혀 있으면 다시 엽니다. PC가 꺼져 있거나 앱 서버가 종료된 동안에는 동작하지 않습니다.

인증번호·캡차·본인 확인 등이 필요하면 자동 처리를 멈추고 앱에 안내합니다. **네이버 연결 창 열기**에서 직접 완료하면 앱이 연결 복구를 인식합니다. 잘못된 비밀번호나 알 수 없는 화면에서는 반복 시도를 중단하고, 이 상태는 앱 재시작 후에도 유지됩니다. 정보를 수정하거나 설정을 다시 저장하면 새로 시도합니다. 연결이 반복해서 만료되면 최소 5분 간격으로 시도합니다. 네이버의 보안 설정은 변경하지 않습니다.

**자동 로그인 끄기**는 체크를 해제한 뒤 저장합니다. **저장된 로그인 정보 삭제**는 암호화된 저장 정보를 삭제하고 자동 로그인을 끕니다. 이미 로그인된 네이버 창의 세션은 유지됩니다. 직접 로그아웃한 상태를 유지하려면 먼저 자동 로그인을 꺼 주세요.

재연결 작업은 리뷰 조회·등록과 같은 대기열에서 처리합니다. 등록 도중 연결이 끊기면 해당 등록을 자동 재전송하지 않습니다. 초안을 확인하고 필요할 때 직접 다시 등록하세요.

**쿠팡 연결 설정**에서도 쿠팡윙 아이디·비밀번호를 한 번 저장해 자동 로그인을 켤 수 있습니다. 쿠팡의 공식 판매자 로그인 폼으로 한 번만 로그인을 시도합니다. 보안 문자·인증번호·기기 확인 등이 필요하면 멈추고 안내하며, **연결 창 · 추가 인증 열기**에서 직접 완료하세요. 잘못된 비밀번호·알 수 없는 화면·중단된 로그인은 반복 시도하지 않고, 확인 대기 상태를 서버 재시작 후에도 유지합니다. 정보를 수정하거나 설정을 다시 저장하면 새로 시도합니다. 반복 만료 시 최소 5분 간격으로 제한합니다.

쿠팡도 앱 실행 중 20초 간격으로 연결을 확인하며, 리뷰 페이지의 실제 서버 로그인 유효 여부 조회는 최대 1분 동안 재사용합니다. 네트워크 장애 때는 비밀번호를 제출하지 않습니다. 쿠팡 재로그인과 리뷰 조회는 같은 대기열에서 처리하며 네이버 설정과 별도로 켜고 끌 수 있습니다. 쿠팡에서 로그아웃 상태를 유지하려면 쿠팡 자동 로그인을 먼저 꺼 주세요.

**에이블리 연결 설정**에서도 같은 방식으로 자동 로그인을 켜고 끌 수 있습니다. 현재 판매자센터의 공식 로그인 폼을 한 번만 제출하고, 추가 인증·보안 문자·잘못된 로그인 정보가 감지되면 멈춥니다. 인증 대기 상태는 서버 재시작 후에도 유지합니다. **연결 창 · 추가 인증 열기**에서 직접 완료하거나, 정보를 수정해 다시 저장하면 됩니다. 에이블리도 20초 간격으로 상태를 확인하며 실제 세션 조회는 최대 1분 동안 재사용합니다. 반복 만료 시 재시도 간격은 최소 5분입니다. 네트워크 장애 때는 로그인 정보를 제출하지 않습니다. 에이블리 리뷰는 계속 조회 전용이며, 재로그인 과정에서 답글을 등록하지 않습니다.

GPT에는 보내지 않습니다.
- 쿠팡 자동 로그인 정보는 같은 방식으로 `.local/coupang-auth.json`에 별도로 암호화합니다. 설정 화면·API 응답에 저장된 아이디·비밀번호를 반환하지 않습니다. 쿠팡의 **저장된 로그인 정보 삭제**는 쿠팡 저장 정보와 자동 로그인만 지우며 네이버 설정이나 현재 쿠팡 브라우저 세션은 유지합니다.
- 에이블리 자동 로그인 정보는 `.local/ably-auth.json`에 같은 Windows 암호화 방식으로 별도 저장합니다. 에이블리 설정을 끄거나 삭제해도 네이버·쿠팡 설정에는 영향을 주지 않습니다. 저장된 로그인 정보는 화면·API 응답·로그·GPT에 전달하지 않습니다.
- 설정 화면에서 입력한 API 키는 `.local/openai-key.json`에 Windows DPAPI CurrentUser로 암호화해 저장하며 서버를 다시 실행하면 자동으로 불러옵니다. 평문 키는 브라우저 저장소, API 응답, 로그, 파일에 기록하지 않습니다. 키 변경 시 새 키를 입력하고 저장하세요. **저장된 API 키 삭제 · 연결 해제**를 누르면 암호문과 실행 중 키를 제거하며, 재시작 후에도 해제 상태가 유지됩니다. OpenAI 계정의 키 자체를 폐기하는 기능은 아닙니다.
- 다른 PC나 Windows 계정으로 옮겨 저장된 키를 읽을 수 없을 때는 앱에서 다시 저장하도록 안내합니다. `.env`의 `OPENAI_API_KEY`는 암호화 저장 기록이 없는 경우에만 초기 값으로 사용할 수 있으며, 앱에서 저장한 키와 명시적인 연결 해제 설정이 우선합니다. `.env.example`에는 실제 키를 넣지 마세요.
- GPT에는 상품명, 옵션(조회한 경우), 평점, 리뷰 내용, 브랜드 지침만 전달합니다. 주문번호와 작성자 ID는 전달하지 않습니다. 리뷰의 일반적인 이메일·휴대전화 형식은 마스킹하며, 자유문장에 있는 모든 개인정보를 자동으로 판별하는 기능은 아닙니다.
- API 사용료는 사용자의 OpenAI 계정에 청구됩니다. API 키는 채팅이나 지원 요청에 붙여넣지 마세요.

## 연동 범위와 운영

에이블리는 `my.a-bly.com/reviews` 화면에서 실제 사용하는 리뷰 조회 GET 요청으로 연결합니다. 공식 공개 API 연동이 아니므로 판매자센터 변경에 따라 수정이 필요할 수 있습니다. 인증 값은 메모리에서만 사용하며 앱 API 응답이나 리뷰 파일에 기록하지 않습니다. 현재 조회는 전체 페이지를 읽은 뒤 작성일 기준으로 선택 기간을 적용합니다. 일부 페이지 누락·리뷰 수 변경·중복이 발견되면 기존 목록을 유지하고 다시 조회하도록 안내합니다. 연결 확인과 동기화는 리뷰 등록·수정 요청을 보내지 않습니다.

네이버 커머스 공개 리뷰 API를 사용하는 앱이 아닙니다. 사용자 소유 계정의 판매자센터 화면을 Playwright로 조작합니다. 검증 기준 화면은 2026-11-15 스마트스토어의 `/mg/contents/review/search` iframe입니다. 네이버 화면 변경, 로그인 상태, 운영 정책에 따라 연결 코드를 수정해야 할 수 있습니다. 장기 운영 전 판매자센터 자동화 허용 범위를 확인하세요.

네이버 연결 창에서 다른 스토어로 바꾸면 기존 목록에 대한 등록을 차단합니다. 먼저 앱에서 리뷰를 다시 동기화하세요. 다른 작업 중에는 앱 연결용 네이버 창을 직접 조작하지 않는 것이 좋습니다.

조회 기간은 최근 1·3·6개월 또는 1년입니다. 가상 스크롤과 페이지 이동으로 리뷰를 모으며 최대 100페이지까지 읽습니다. 화면에 표시된 전체 건수와 수집 건수가 다르면 기존 캐시를 유지하고 오류를 알립니다.

쿠팡은 로그인된 전용 Chrome의 쿠팡윙 `/tenants/cs/product/review` 화면과 같은 세션에서 실제 화면의 `/tenants/cs/product/review/search` 조회 요청만 사용합니다. 공개 Open API 연동은 아니며 쿠팡윙 변경 시 조정이 필요할 수 있습니다. 판매중·판매종료 상품을 모두 포함하고, 쿠팡의 1개월 조회 제한에 맞춰 최대 28일씩 기간을 나눠 모든 페이지를 합칩니다. 조회 건수와 실제 수집 건수가 다르거나 조회 도중 판매자 계정이 바뀌면 기존 캐시를 보존합니다. 최대 300개 조회 요청을 허용하며 초과하면 기간을 줄이도록 안내합니다.

쿠팡 로그인은 전용 Chrome 프로필에 유지됩니다. 자동 로그인을 설정하면 만료 시 재연결을 시도합니다. 추가 인증이 필요하거나 자동 로그인을 꺼 둔 경우 **쿠팡윙 연결/열기**에서 직접 완료한 뒤 다시 새로고침하세요. 네이버와 쿠팡의 자동 로그인은 각각 설정합니다. 쿠팡 연결 창은 조회 중 직접 조작하지 마세요.

등록 직후 연결이 끊기는 등 결과가 불명확하면 재전송하지 않고 상태를 기록합니다. **네이버 답글 확인**으로 결과를 확인하세요. 같은 문구 재등록은 중복 방지를 위해 차단합니다. 이미 등록된 글의 수정·삭제가 필요하면 판매자센터에서 직접 처리하세요.

등록 완료 안내창은 앱이 닫은 뒤 네이버의 실제 답글을 다시 읽습니다. 등록 후 확인 단계만 실패했을 때에도 재등록하지 않고 조회로 결과를 복구합니다. 등록이 확인되면 초안과 미확인 기록을 정리하며, 다른 앱 탭에도 5초마다 또는 탭으로 돌아왔을 때 저장된 등록 상태를 반영합니다. 이 화면 갱신은 로컬 저장 상태를 읽고, 스토어 전체 리뷰 조회는 위 자동 가져오기 주기로 별도 수행합니다.

## 구성과 검증

- `src/naver.js`: 전용 브라우저, 리뷰 수집, 대상 검증, 등록 및 재조회
- `src/coupang.js`, `src/coupang-service.js`: 쿠팡 조회 전용 연결, 기간·페이지 분할, 통합 캐시
- `src/ably.js`, `src/ably-service.js`: 에이블리 조회 전용 연결, 만족도·사진·작성 기간, 통합 캐시
- `src/ably-login.js`: 에이블리 공식 로그인 폼, 단일 로그인 시도, 추가 인증 대기
- `src/auto-sync.js`: 등록된 모든 스토어·매장 채널의 자동 리뷰 조회, 주기·실패·복구 상태, 중복 작업 방지
- `src/coupang-login.js`: 쿠팡 공식 로그인 폼 확인, 단일 로그인 시도, 추가 인증 대기
- `src/naver-login.js`, `src/auto-login.js`: 정상 로그인 시도, 추가 인증 대기, 중복 시도 방지
- `src/auth-vault.js`: Windows 사용자 계정에 묶인 로그인 정보 암호화 저장
- `src/core.js`: 초안 저장, 사용자 확인 토큰, 중복·불확실한 등록 방지
- `src/ai.js`: OpenAI Responses API로 초안만 생성
- `src/api-key-vault.js`: OpenAI 키 암호화 저장·시작 시 복원·삭제
- `src/server.js`: 동일 출처·CSRF 검사와 로컬 API
- `public/`: 반응형 리뷰 목록, 필터, 답글 편집기, 설정 화면

`npm test`는 등록 경로와 HTTP 경계 테스트를 수행합니다. 브라우저 UI 테스트는 로컬 서버가 실행되어 있어야 하며 모든 API를 모의 처리하므로 실제 고객 리뷰를 게시하지 않습니다. `npm run check`는 JavaScript 구문 검사입니다.

`scripts/verify-live.mjs`는 이미 등록된 답글만 재조회합니다. `scripts/verify-fill.mjs`는 미답변 리뷰 입력창에 임시 문구를 입력한 후 지우며 등록 버튼을 누르지 않습니다. `scripts/screenshots.mjs`는 실제 화면의 데스크톱·모바일 레이아웃을 확인합니다.

`scripts/verify-coupang.mjs`는 네이버의 마지막 조회 기간에 맞춰 실제 쿠팡 리뷰만 새로고침하고, 네이버 리뷰·초안 보존 및 데스크톱·모바일 조회 전용 화면을 검증합니다. 리뷰를 게시하지 않습니다.

`node scripts/verify-ably.mjs 6m`은 실제 에이블리 리뷰를 읽어 건수·기간·사진·만족도를 확인하며 앱 캐시는 변경하지 않습니다. `node scripts/check-ably-app.mjs`는 실행 중인 앱에 에이블리 리뷰를 동기화하고, 다른 스토어의 리뷰·초안 보존 및 실제 사진·스토어별 탭·모바일 화면을 검증합니다. 두 스크립트 모두 에이블리 연결 창에 로그인한 상태가 필요하며 리뷰를 게시하지 않습니다.

`node scripts/verify-ably-login.mjs`는 저장된 에이블리 자동 로그인 정보로 별도 임시 브라우저 세션에서 실제 로그인과 리뷰 조회를 검증합니다. 현재 연결 창과 앱 캐시는 변경하지 않으며, 결과와 건수만 출력합니다. 검증 세션에서 추가 인증이 요구되면 자동 처리를 멈추고 결과를 알립니다.

외부 호스팅은 포함하지 않습니다. 이 PC에서 앱 서버와 연결용 브라우저를 실행해 사용합니다.
