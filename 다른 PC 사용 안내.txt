Review Desk — 다른 Windows PC에서 사용하기

v1.3.0 주요 기능
- 리뷰 관리 / 문의 관리 탭 아래의 문의 알림 창에서 네이버·쿠팡·에이블리 문의를 확인합니다.
- 리뷰 화면에서도 30초마다 확인할 문의를 갱신하고, 문의 종류를 누르면 답변 대기 대화를 엽니다.
- 앱 안에서 대화 조회·답변·GPT 초안 생성, 에이블리 문의 완료 처리를 지원합니다.
- 기존 PC 업데이트 시 리뷰·문의·초안·로그인 정보·GPT 키는 해당 PC에 유지됩니다.

권장: 설치 파일 하나로 설치하기
1. https://github.com/hyeonjeong222/teawest-review-desk/releases/latest 에서
   ReviewDesk-Setup-x64.exe를 내려받아 더블클릭합니다. GitHub 로그인은 필요 없습니다.
2. ‘설치하기’를 누릅니다. 예전 ZIP 앱을 썼다면 자동으로 찾은 폴더를 확인하세요.
   찾지 못하면 ‘폴더 선택’에서 예전 ‘리뷰관리 실행.cmd’가 있는 폴더를 선택하세요.
   같은 PC, 같은 Windows 사용자 계정에 저장한 로그인 정보와 API 키를 가져옵니다.
3. ‘리뷰 앱 열기’를 누릅니다. 다음부터 바탕화면의 ‘리뷰 관리’를 더블클릭하세요.
4. 처음 쓰는 PC라면 각 스토어 연결 설정에 로그인 정보를 저장합니다.
   ‘브랜드 · GPT 설정’에 본인 API 키를 저장합니다. 추가 인증만 직접 완료하세요.

설치형 앱 업데이트
- 앱 오른쪽 위 ‘업데이트 → 업데이트 확인 → 다운로드 및 설치’를 누릅니다.
- 설치 창이 열리면 설치를 마치고 ‘리뷰 앱 열기’를 누릅니다.
- 저장한 정보는 %LOCALAPPDATA%\ReviewDesk\data 에 따로 보관해 유지됩니다.
  이 폴더를 삭제하면 저장 정보가 없어집니다.
- 최신 설치 파일을 다시 내려받아 실행해도 업데이트할 수 있습니다.
- 설치형으로 옮긴 뒤에는 예전 실행 파일 대신 새 바탕화면 바로가기를 사용하세요.
- 현재 설치 파일은 코드 서명이 없어 Windows에 게시자 확인 안내가 나올 수 있습니다.

기존 ZIP 방식 (선택)

1. ReviewDesk-Windows-x64 ZIP 파일을 새 PC로 복사합니다.
2. ZIP을 바탕화면 등 쓰기 가능한 폴더에 '모두 압축 풀기' 합니다.
   ZIP 안에서 바로 실행하지 마세요. OneDrive 공유 폴더 대신 PC별 폴더를 권장합니다.
3. Chrome 또는 Edge가 설치되어 있는지 확인합니다.
4. '리뷰관리 실행.cmd' 또는 'Start Review Desk.cmd'를 더블클릭합니다.
   Node.js와 필요한 모듈이 포함되어 별도 Node.js 설치나 npm 명령이 필요 없습니다.
5. 기존 PC 앱에서 '다른 PC로 로그인 정보 옮기기'를 누릅니다.
   10자 이상의 이전용 암호를 정하고 '암호화된 이전 파일 만들기'를 누릅니다.
   내려받은 review-desk-login-날짜.json 파일을 새 PC로 옮깁니다.
6. 새 PC 앱의 같은 메뉴에서 이전 파일과 암호를 입력하고 복원합니다.
   다섯 스토어의 로그인 정보와 자동 로그인 설정, GPT 키가 함께 저장됩니다.
   다음 실행부터 다시 입력하지 않아도 됩니다. 추가 인증만 직접 완료하세요.
   이전 파일이 없다면 연결 설정과 '브랜드 · GPT 설정'에서 직접 입력할 수도 있습니다.
7. 조회 기간을 선택해 전체 스토어를 새로고침합니다.

사용 조건
- Windows 10/11 64비트(x64), Chrome 또는 Edge, 인터넷 연결이 필요합니다.
- 웹앱은 각 PC의 127.0.0.1에서만 실행됩니다. 외부 배포나 서버 가입은 필요 없습니다.
- 이 압축 파일에는 현재 PC의 리뷰·초안·API 키·비밀번호·로그인 세션이 없습니다.
- 각 PC의 리뷰 캐시와 초안, 설정은 독립적입니다. PC 사이에 자동 공유되지 않습니다.
- 한 PC에서 등록한 실제 답글은 다른 PC에서 다음 리뷰 조회 후 표시됩니다.
  답글 등록 전에는 판매자센터의 현재 상태를 다시 확인해 중복 등록을 막습니다.
- 앱 폴더는 실행 중 이동하지 마세요. .local 폴더를 삭제하면 해당 PC의 저장 정보가 사라집니다.
- 기존 PC의 .local 폴더 전체 대신 암호화된 로그인 이전 파일을 사용하세요.
  새 PC에서 복원하면 해당 Windows 계정으로 다시 암호화해 저장합니다.
- 이전용 암호는 앱에서 복구할 수 없습니다. 잊으면 기존 PC에서 새 파일을 만드세요.
  파일에는 로그인 정보가 있으니 본인의 PC 사이에서만 전달하세요.
- 복원은 파일에 포함된 로그인 정보와 GPT 키를 교체합니다. 포함되지 않은 계정은 유지합니다.
  비밀번호 변경 사항은 자동 공유되지 않으므로 사용하는 PC마다 수정하거나 새 파일을 복원하세요.
- 새 PC를 시작할 때 실행 파일을 다시 더블클릭하세요. Windows 자동 시작은 설정하지 않습니다.

기존 리뷰와 작성 중인 초안까지 옮기고 싶을 때 (선택)
- 두 PC에서 앱 서버를 종료한 상태에서만 진행합니다.
- 새 PC에서 아직 앱을 실행하지 않았다면, 압축을 푼 폴더 안에 .local 폴더를 만들고
  기존 PC의 .local/state.json 파일 하나만 복사할 수 있습니다.
- 이미 새 PC에서 사용했다면 먼저 그 PC의 state.json을 별도 백업하세요.
  복사는 병합이 아니라 기존 리뷰·초안·설정을 바꾸므로 두 PC의 초안은 자동 합쳐지지 않습니다.
- state.json에는 리뷰 내용과 작성 중인 초안이 있으니 본인 PC 사이에서만 전달하세요.
- state.json에는 자동 로그인 정보와 GPT 키가 없습니다. 위 로그인 이전 파일로 별도 복원하세요.

문제 해결
- 로그인했는데 앱에 연결 안 됨으로 표시되면 '연결 상태 진단.cmd'
  (또는 'Check Connection.cmd')를 실행하세요. 최대 약 25초 뒤 결과가 나옵니다.
  .local 폴더의 connection-diagnostic-날짜.txt 파일 내용을 보내 주세요.
  아이디·비밀번호·API 키·쿠키·리뷰·전체 주소는 기록하지 않습니다.
  진단은 로그인이나 설정 변경을 하지 않으며, 문제가 생긴 PC에서 실행해야 합니다.
- 화면이 열리지 않으면 .local/server-error.log를 확인합니다.
- 연결 창을 찾지 못하면 Chrome 또는 Edge를 설치하고 앱을 다시 실행합니다.
- 같은 PC에서 앱 복사본 두 개를 동시에 실행하면 먼저 실행한 앱이 열립니다.
- 추가 인증은 연결용 브라우저에서 직접 완료하세요. 비밀번호를 채팅에 보내지 마세요.
